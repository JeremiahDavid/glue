Logo documentation

This document is the single source of truth for the hiveflowAI mark. It supersedes every colorway and shape variant explored earlier — Black / Gold (ink rim, amber core) is the only approved logo. Anything built from this point forward, by anyone or anything, should reference this file rather than an earlier exploration sheet.

01

The mark

A rounded hive cell in ink, with a gold core connected to the rim by six curved walls. The rim is the boundary you can trust; the core is the resolved model living inside it; the walls stand in for the relationships in the data itself. Two colors only — ink and gold. Green does not appear in the mark; it remains the interface's interactive accent elsewhere in the system.

02

Construction

Built on a regular hexagon. Annotation lines below are shown in green only because green is not used anywhere in the mark itself — it's a safe, unambiguous color for spec overlays and never appears in a real reproduction of the logo.

R = 92 units, outer circumradius. r = 39 units (0.42R), core circumradius. Six vertices at 60° intervals define both hexagons on the same angles, which is what lets the connecting walls run as straight radii between them. Corner fillet = 14 units on the rim, 6 units on the core. All values live in a 240×240 unit viewBox.

03

Clearspace & minimum size

Clearspace is defined as X, where X equals the core's own radius (39 of the 240 units the mark is drawn on — about 16% of the mark's width). Keep at least X clear on every side before any other element, text, or edge of the frame.

Below 24px, switch from the two-tone mark to the mono silhouette — the gold core reads as noise before the rim shape does. Shown here at true size.

24px — full color, floor
16px — mono
12px — mono, favicon floor
Below 12px, don't reproduce the mark at all — use initials or omit it. The rounded corners collapse into a blob past this point.

04

Color variants

Primary — light backgrounds
Reversed — dark backgrounds
Mono — favicons, stamps, single-color contexts

05

Lockups

Two approved arrangements. Icon-to-wordmark gap is 2X (twice the clearspace unit) in both.

Horizontal — nav bars, headers, letterhead
Stacked — square avatars, app tiles, splash screens

06

Incorrect usage

×
Don't recolor. Ink and gold only — no green, no arbitrary palette.
×
Don't rotate. The mark is always upright.
×
Don't stretch. Scale uniformly, never independently on one axis.
×
Don't add shadows or gradients. Flat color only.
×
Don't place on low-contrast backgrounds. Gold on gold-adjacent tones disappears.

hiveflowAI

08

Governing rules

  • This file is canonical. If an earlier sheet in this project conflicts with it, this file wins.
  • Two colors, no exceptions — ink #29271F and gold #9C5E28. Green (#2B6A4B) never appears in the mark; it's reserved for spec annotations in this document and for interactive UI elsewhere.
  • No gradients, no drop shadows, no rotation, no non-uniform scaling. The geometry in Construction is exact — reproduce it, don't approximate it.
  • Icon always precedes the wordmark in both lockups, never the reverse.
